## Email body

Hi,

A goal that says "all tests pass" can be met by deleting the failing test.

That is the catch with Claude Code's /goal. After every turn, a separate small model checks your condition. It reads only the conversation. It does not run commands or open files. So a vague condition fails two ways: Claude meets it the cheap way, or nothing in the conversation can prove it and the goal never resolves.

### Build: The Rewrite

One weak instruction, fixed. Usable without clicking anything.

**Before**

```
/goal all tests pass
```

**After**

```
/goal uv run pytest tests/auth exits 0, with no file under tests/ modified, or stop after 20 turns
```

**Why it works:** one end state, a check whose output lands in the conversation, a constraint on what must not change, and a cap on turns. Swap in your own test command and folder.

Using the Ralph loop plugin instead? Set `--max-iterations` yourself. It defaults to unlimited.

Know an engineer who lets Claude Code run unattended? Forward them this section.

### Career: the habit that marks a strong agent design answer

The prompt: "Design an AI agent that handles refund requests." Split read tools from write tools before the interviewer asks.

In the worked example that is three read tools (order, policy, customer history) and two write tools (issue a refund, escalate). The limit lives in the tool: issue_refund rejects any amount above the order total, and an idempotency key means a retry after a timeout cannot refund twice.

The 45 minutes: 0 to 5 clarify, 5 to 10 budgets, 10 to 25 architecture and tools, 25 to 35 three failure modes, 35 to 45 evals and rollout. ### The Take: CLAUDE.md is the last place to fix a mistake

When Claude repeats a mistake, work down this list and stop at the first that fits:

1. Design it out, so the wrong call cannot be written.
2. Add a lint, type or import rule.
3. Add a hook or deny rule.
4. Write a CLAUDE.md line.

The reasoning, from Lauren Tan's talk "All Code Is Slop (Except Mine)": a check gives the same answer every time, and a line in a markdown file does not. Her team reports about 11,000 pull requests merged in a month, about half a percent reverted. One team's own figure, not a benchmark. The order is the part to copy.

For rule 2, write the error message for Claude. It is the prompt Claude reads at the moment it makes the mistake:

```toml
[tool.ruff.lint]
extend-select = ["TID251"]

[tool.ruff.lint.flake8-tidy-imports.banned-api]
"openai".msg = "Call models through app.llm.client. It owns retries, timeouts and logging."
```

Then clean up the old cases, because Claude copies the patterns it finds in your repo. More: [Claude Code Best Practices](https://aiengineerinsights.com/blog/claude-code-best-practices/?utm_source=newsletter&utm_medium=email&utm_campaign=brief-2026-11-25).
