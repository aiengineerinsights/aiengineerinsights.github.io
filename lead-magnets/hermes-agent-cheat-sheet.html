Hermes Agent Cheat Sheet

Install, configure, fix and run Nous Research's open-source agent. One page.
AI Engineer Insights
aiengineerinsights.com · Oct 2026

1 · Install

curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bashOfficial installer (macOS, Linux, WSL2)
pip install hermes-agentPython install
docker pull nousresearch/hermes-agent:latestContainer image
docker run -it -v ~/.hermes:/root/.hermes nousresearch/hermes-agent:latestRun it; the volume keeps config and memory between runs
Windows: run the agent under WSL2. If PowerShell blocks the script, use an Administrator shell or install inside WSL2.

2 · First run & models

hermes setup --portalEasiest start: Nous Portal model + Tool Gateway tools
hermes modelChoose or switch provider and model, paste API key
hermes / hermes --tuiStart the agent (modern TUI)
hermes gateway setupTelegram, Discord, Slack, WhatsApp, Signal
Rule: the model needs a context window of at least 64,000 tokens, or the first message fails.

3 · Sessions

hermes --continue / hermes -cResume your last session
hermes sessions listFind a saved chat
/modelSwitch model inside a session
/voice onVoice mode (needs the voice extra)

4 · Skills

/skillsBrowse skills inside a session
/skill skill-nameLoad a skill mid-session
hermes -s "skill-name"Load a skill at launch
hermes skills createScaffold a new skill
~/.hermes/skills/Where skills live
Turn on write_approval so skills the agent writes are staged for review, not applied silently.

5 · Web UI & desktop

hermes dashboardStart the local web dashboard
http://127.0.0.1:9119Open it in any browser (runs locally)

6 · Files that matter

~/.hermes/.envAPI keys and secrets
~/.hermes/config.yamlSettings
~/.hermes/skills/Skills

7 · Fix it

hermes doctorRun first. Checks PATH, keys, model, build
hermes doctor --fixSame checks plus automatic repairs; YAML and custom-provider issues are left for you
hermes updateLatest version, then re-run hermes doctor
hermes: command not foundsource ~/.zshrc or source ~/.bashrc, or open a new terminal
Context-window errorhermes model, pick a 64k+ model
Provider / auth failedCheck the key in ~/.hermes/.env, then hermes model
Docker forgets everythingMount -v ~/.hermes:/root/.hermes

8 · Migrate

hermes claw migrateImport an OpenClaw setup (preview first)
hermes import-agent claude-codeBring CLAUDE.md, permissions and MCP servers across
Full guides: Troubleshooting · Alternatives · vs OpenClaw
