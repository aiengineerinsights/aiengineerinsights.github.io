Claude Code Cheat Sheet

Slash commands, keyboard shortcuts and CLI flags. One page. [x] optional, <x> required.
AI Engineer Insights
aiengineerinsights.com · Nov 2026

1 · Every day

/initCreate a starter CLAUDE.md
/plan [task]Plan first, edit after approval
/model [model]Switch model
/contextSee what fills the context window
/compact [focus]Summarize to free context
/clear [name]New conversation, memory stays
/resume [session]Reopen an earlier session
/rewindRoll back code, chat or both
/diffReview working-tree changes
/code-review [--fix]Check the diff for bugs
/permissionsAllow, ask and deny rules
/mcpManage MCP servers

2 · Set up

/memoryEdit CLAUDE.md, auto memory
/add-dir <path>Add a working directory
/cd <path>Move session, keep conversation
/hooksView hook configuration
/skillsList skills
/pluginPlugin menu
/terminal-setupInstall Shift+Enter newline
/statuslineSet up the status line
/config [key=value]Settings

3 · Run work

/goal [condition]Work until a condition is met
/loop [interval] [prompt]Repeat a prompt
/tasksBackground work in this session
/subtask <task>Forked background subagent
/backgroundDetach session (alias /bg)
/fork [prompt]Copy into a background session
/btw [question]Side question, not saved
/effort [level]low to xhigh, max, auto
/usageCost and limits (/cost, /stats)

4 · Review and ship

/security-reviewSecurity check of branch changes
/simplify [target]Clean up changed code
/verifyBuild, run and confirm a change
/autofix-prCloud session that fixes the PR
/branch [name]Branch the conversation
/rename [name]Name the session
/export [file]Export as plain text
/copy [N]Copy a response

5 · Shortcuts

Shift+TabCycle permission modes
EscInterrupt Claude
Esc EscClear draft, or rewind menu
Ctrl+CInterrupt; twice to exit
Ctrl+RSearch prompt history
Ctrl+BSend task to background
Ctrl+OTranscript viewer
Ctrl+TTask checklist
Ctrl+GEdit prompt in your editor
Ctrl+SStash / restore prompt
Ctrl+VPaste image
Option+P / Alt+PSwitch model
Ctrl+J or \ + EnterNew line, any terminal
?Shortcut help (empty prompt)

6 · Prefixes and editing

/Command or skill
!Shell mode
@Mention a file
Ctrl+A / Ctrl+EStart / end of line
Ctrl+K / Ctrl+UDelete to end / to start
Ctrl+WDelete previous word
Ctrl+YPaste deleted text
Ctrl+_Undo input edit

7 · CLI

claude "query"Start with a prompt
claude -p "query"Answer, then exit (scripts, CI)
claude -cContinue last session
claude -r <name>Resume by name or ID
claude -w <name>Run in a git worktree
claude --bg "task"Run as background agent
claude updateUpdate
claude doctorInstall diagnostics
claude mcpConfigure MCP servers

8 · Flags

--model <name>sonnet, opus, haiku, fable
--permission-mode <mode>default, acceptEdits, plan, auto
--add-dir <path>Extra working directory
--output-format jsonPrint-mode output format
--max-turns <n>Limit turns (print mode)
--append-system-promptAdd to the system prompt
--bareSkip hooks, skills, MCP, CLAUDE.md
--safe-modeCustomizations off, to debug
Custom command: put a SKILL.md in .claude/skills/<name>/ and type /<name>. Use $ARGUMENTS for what follows the command.
Gone: /vim (use /config), /pr-comments, /ultraplan, --enable-auto-mode. /cost and /review are now aliases.
